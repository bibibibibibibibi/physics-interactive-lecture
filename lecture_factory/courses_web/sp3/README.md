## 模拟

- `oscillator-model.mjs`：给定初值的线性受迫振子完整解，含无阻尼、欠阻尼、临界、过阻尼及精确无阻尼共振。
- `sim-resonance.html`：完整响应、六组频率、四组阻尼、稳态扫频、相位及三条阻尼峰对照。频率/阻尼观察窗为 12/14 秒，保留暂态并显示理论稳态振幅。
- `sim-mri.html`：净磁化在有效场下的旋转、固定九十度匹配脉冲与失谐对照、接收阶段的定性进动和衰减。区分旋转与实验室参考系；不代替成像编码与重建模型。

P5、P6、P7、P13 的第 2 步有开始提示，以便现有构建器生成真实 `stepTimes[2]`。四个自动模式从父课堂的真实音轨与步时取时钟，倒退可重建状态。P11、P15 保留手动操作；MRI在第2步自动重建4秒激发与6秒收信过程，并保留暂停后的手动操作。六个源视频也按父课堂时间重建播放位置。旧完整候选的同步实测已通过；新MRI派生片需重新测试P20的9.2秒循环。

## 私有候选流水线

临时脚本、缓存、审阅、截图和所有构建产物位于 `work/special-series/sp3/`。在仓库根执行：

```bash
.venv/bin/python -B lecture_factory/courses_web/sp3/author.py
```

原人类授权与六句补充直接授权分别保留证据。六句 SA04–SA09 已全部在第一次同服务请求成功；原178句缓存字节保持不变。完整184句登记只用于本地装配，不增加外发范围。旧通用 `make_audio_neural.py` 已禁用在线路径，仅可 cache-only；专用六句 runner 保留已成功的全局尝试记录，不能重发成功句。

后续只使用本地缓存，依次执行：

```bash
.venv/bin/python -B work/special-series/sp3/pipeline/prepare_quiz_gap.py --assemble
.venv/bin/python -B work/special-series/sp3/pipeline/build_candidate.py
.venv/bin/python -B work/special-series/sp3/pipeline/accept_audio.py
node work/special-series/sp3/pipeline/build_preview.mjs --classroom
node work/special-series/sp3/pipeline/build_preview.mjs --slides
.venv/bin/python -B work/special-series/sp3/pipeline/export_candidate.py
.venv/bin/python -B work/special-series/sp3/pipeline/serve_candidate.py --port 8095
```

私有课堂构建的单课程目录仅用于本地验收；共享菜单、public、dist 和 Git 由总协调者管理。

音频 helper 保存逐句神经来源、真实 PCM 时长及文本签名；完整缓存前检失败时不进入共享 builder 的重配分支。构建只调用私有输出路径，Vite 使用程序化 API 与私有缓存。最终全课 MP3 用真实页面 PCM 和每页 0.8 秒间隔组合，需核对解码时长与时间线。

四个题目邀请句之后的静音固定为1.2秒，以便倍速播放时播放器有暂停余量。P6 index6、P16 index1、P17 index2的原间隔为0.4秒；P23 index1以问号结束，原间隔为0.65秒。四处共增加2.95秒（70800个24kHz PCM帧）。新组装保留全部原逐句MP3和旧页缓存，只重组四个题页；其余21页保持字节相同。早期六句缺失的拒绝报告保留为历史。完整音轨的四题已完成1倍速正确作答及2.5倍速错误作答的八次实际暂停与继续，证据绑定当时源与renderer；最终源仍需核对其时间身份。

原文最后一句曾遇连接及10秒响应超时；本地证明现有SDK构造器接受30秒响应等待后，仅对该原句做一次同服务请求并成功，真实PCM为198720帧、8.280秒。原helper及node_modules保持原样，探测无自动重试；详细证据在私有 `pipeline/timeout-probe-result.json`。这一成功不单独证明超时调整是唯一原因。

静态导出是 HTTP 演示包：JS、CSS、字体与图片可内联，视频、模拟及元数据仍依赖配套 `weblec/sp3/`。不得把单个 HTML 标记为完全离线单文件。
