### 一个重要纠正
**「`git add -A` 会加 1178 MB」是错的**。我先用 `git status --porcelain` 的未跟踪目录按全量累加，
但 `.gitignore` 第 14 行早就有 `lecture_factory/courses_web/*/audio/*.mp3`，页音频本来就不入库。
正确口径是 `git ls-files --others --exclude-standard`：
**1787 个文件 / 523 MB，其中 502 MB 是 `public/weblec/*/audio.mp3`（整轨）**。
以后算待入库体积必须用这个命令，不能用 `git status` 的路径自己 walk。

### 为什么整轨不能排除
`interactive-lecture/scripts/check-release.py` 的 `git_check()`：把部署遍历到的所有
`APP/public/**` 文件都要求出现在 `git ls-files` 索引里（`Required release file is not in Git index`），
CI 的 portability 工作流就跑这一步。所以 `public/weblec/<id>/audio.mp3` **必须入库**，
`courses_web/*/audio/*.mp3` 才是不必入库的那一半。`docs/repository-storage.md` 里写的就是这个分工。
