# 专题系列课件制作经验（sp 课）

> 适用对象：**专题系列**（sp1、sp2……，每个约 20 分钟的教学节段，用 special 主题、
> 分段导航、随堂互动题、嵌入模拟/视频）。
> **不适用于第九章这类常规课堂**（7~11 分钟的轻量课）——常规课沿用本 README 主流程
> 与 default 主题即可，不要把专题的重型做法（分段导航、大段讲稿、embed 档）带过去。

sp1《角动量守恒定律》从开工到精修定稿的全部经验，sp2 起照单执行。

## 一、教学设计

1. **推导链不能跳步**：守恒定律不能空降——「F=dp/dt（已学）→ 类比得 M=dL/dt
   （角动量定理）→ M外=0 推出守恒（特例）」。缺中间环，学生就会觉得结论是背下来的。
   推广：任何定律先给「它从哪来」，再给「怎么判断/使用」。
2. **首尾呼应**：引入抛的悬念（苏翊鸣、空间站），小结必须逐一当面解答。
3. **术语自洽**：课里没演示过的东西后文不许出现（sp1 曾把转台误写成转椅/办公椅），
   全部统一到实际使用的意象；封面不要提前抛引入页的问题。
4. **不重复**：上一页给出的公式下一页不再展示；刚讲完的内容不立刻拿来提问
   （无效 quiz）。
5. **互动题一律用选择题**：有明确作答点、对错判定、解析；开放题没有作答入口，
   体验差（sp1 初期两道开放题都改成了选择题）。
6. **时长配比**：新授:应用 ≈ 2:1；重点难点段时长必须给够；TTS 实际语速约
   **280 字/分**（远快于直觉预估的 150~200），20 分钟课 ≈ 4800~5200 字讲稿——
   以 `build_web.py` 输出的逐页真实时长校准，别按字数估算。

## 二、视觉与主题（special 主题约定）

7. 主题参数从专题 PPT 提取：淡蓝渐变底、logo 右上、无通栏页眉字、页内顶格小节标题
   三件套（`sp_header(编号, 标题)`，封面/目录页不加）、目录页（含重点/难点红标）、
   封面无页码。
8. 分段导航用 `sections`（按目录大段），不按页码；段首页要对齐内容段的真实起点。

## 三、模拟与媒体嵌入

9. 标准流程（README「嵌入交互模拟」一节的五步）：拿原始 HTML → 本地化（vendor/
   零 CDN）→ embed 精简档（`?embed=1` 场景 / `?embed=chart` 含图表 / `?embed=record`
   现场记录曲线，按页选档，一个模拟可服务多页）→ 需要讲稿遥控时加 postMessage
   接口（msgs 锚步进，demo/reset）。
10. embed 档内布局要和讲稿方位词一致（讲稿说「左下角有张记录图」，图就得在左下）。
11. **数据曲线教训**（sp1 实测 bug）：采样按时间序连线，回拖就折叠乱线——要按横轴
    分桶覆盖 + 排序连接；「重置」必须恢复基准值并清空轨迹，否则新旧数据错位。
12. embed 模式相机要拉近，3D 主体不能太小。
13. 视频素材：PPT 里没有就用 yt-dlp 从 B 站找（`bilisearch`；YouTube 国内不可达），
    抽帧挑片段、剪到 ~30s、转 H.264（AV1/HEVC 兼容性差）、静音循环。分工：
    **要交互用 `html()`（模拟），只要画面动用 `video()`（实拍/CG）**。

## 四、工程流程

14. PPT 分析产物是一切工作的基准：`待处理/<课名>源文件与分析/`（逐页 PNG +
    `ppt_structure.json` 动画步序 + `ppt_geometry.json` 几何 + media 提取与页↔媒体
    映射）。
15. 音频缓存按页 id：**插页时降序改名**缓存文件（`page{n}.mp3`、`page{n}.times.json`、
    `p{n}_*.mp3`、`_list{n}.txt`），全课十几分钟的音频不用重配；平时改动只删受影响
    页的 `page<n>.mp3` + `.times.json` 再重建。
16. 每轮改动浏览器实测截图确认 + `validate_weblec.py shm` 回归（护住第九章常规课）。
