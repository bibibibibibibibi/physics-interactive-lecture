# 大学物理课程质量工程

## 目标与原则

以“科学正确、概念清楚、教学有效、视觉统一、运行可靠、证据可复查”为课程质量标准。先完成《5-1 电荷 库仑定律》（`kin5-1`）样板课，再将同一流程推广到整章和全课程。

原则性、概念性错误优先于视觉美化；构建成功不等于课程验收通过；任何自动检查都不能替代教师完整听审和学生试用。

## 缺陷分级

| 等级     | 定义                                    | 示例                            | 放行规则                |
| ---    | ---                                   | ---                           | ---                 |
| A：阻塞   | 科学错误、概念误导、公式或单位错误、图示方向错误、音画不一致、核心交互失效 | 力的大小漏绝对值、电子转移方向画反、字幕已改但仍使用旧配音 | 必须清零后才能进入教学交付候选     |
| B：必须修订 | 重要条件缺失、阅读顺序混乱、文字与图区交叠、内容裁切、题卡不能自然暂停   | 未说明矢量下标约定、平衡点在讲解前被图透答案        | 样板课必须清零；推广课须登记并限期修复 |
| C：改进   | 风格不统一、框体过宽、措辞可更简洁、提示可更清楚              | 声明宽度大于实际内容、提示框视觉过重            | 不单独阻塞运行，但样板课应集中处理   |
|        |                                       |                               |                     |

## 每课工作流

1. **基线冻结**：保存课程数据哈希、逐页稳定截图、版式报告、控制台和资源错误、数值复算结果。
2. **科学审查**：逐页核对正文、讲稿、公式、单位、图示、预设问答和题卡；记录适用条件与模型边界。
3. **教学修订**：明确学习目标，在关键推演前安排预测或诊断；错误选项必须对应真实误区，并给出逐项反馈。
4. **视觉与交互修订**：统一主题、层级、留白和图版；先保证阅读顺序与无裁切，再处理装饰。
5. **可重复构建**：正文、热点、预设问答、互动锚点均进入源稿或明确的源数据；禁止依赖一次性手工后处理。
6. **音频一致性**：讲稿变化页必须重配；逐句缓存文字、时间轴、字幕和音频一致后才能发布。
7. **技术复验**：结构校验、真实浏览器逐页检查、题卡实际操作、控制台与资源检查、生产构建。
8. **人工验收**：逐页查看最终稳定截图；完整听审、教师确认与学生试用分别记录，不相互冒名顶替。

## 验收闸门

| 验收项 | 通过条件 | 证据 |
| --- | --- | --- |
| `technical_passed` | 结构校验无错误；浏览器零控制台错误、零资源 404；无 A/B 版式阻塞；题卡可触发、暂停、作答、反馈、继续；生产构建成功 | 校验输出、`report.json`、逐页与题卡截图、构建日志 |
| `physics_reviewed` | 逐页正文、讲稿、公式、单位、图示和预设问答完成独立复核；数值经过复算；无已知原则性或概念性错误 | 逐页科学审查记录、数值复算记录 |
| `instructional_reviewed` | 目标、推演顺序、诊断题、反馈、小结一致；不在提问前泄露答案；术语与符号前后统一 | 逐页教学审查记录、题卡截图 |
| `human_listening` | 教师或指定听审人完整听过最终音轨，确认发音、停顿、口播与字幕 | 听审人、日期、问题清单及关闭记录 |
| `teacher_accepted` | 课程负责人确认可交付 | 明确确认记录 |
| `student_trial` | 至少一次目标学生试用，记录理解障碍与交互问题并处理 | 试用记录与修订闭环 |

只有实际取得对应证据的项目才能标记为通过。没有真人完整听审时，只能报告“物理复核与技术验收通过”，不能报告“整课教学交付全部完成”。

## 样板课本轮范围

- 修正正文、讲稿、图示和预设问答中的科学问题。
- 在 P4、P8、P11 设置三道诊断题，分别检查电荷量子化边界、作用力与反作用力、第三个电荷的平衡位置。
- 新增可复用的 `refined` 视觉主题，只用于本课，不改变其他课程既有主题。
- 将原有热点与预设问答纳入可重复构建，避免重跑创作脚本时丢失。
- 重配讲稿发生变化的页面，未改页复用原有音轨。
- 保存修订前后证据，并按上表分别给出验收结论。

## 推广顺序

1. 样板课达到 A/B 缺陷清零，且技术、物理、教学三项证据齐全。
2. 将通用规则加入课程校验和浏览器检查，不为追求指标盲目缩小所有框。
3. 按章逐课推广，每课保留基线、修订、复验、验收四类记录。
4. 教师完整听审与小规模学生试用后，再决定全课程统一发布。
